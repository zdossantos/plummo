# Maquettes Plummo

Fichier : https://www.figma.com/design/6kioGGc1qTiFtyAjvsHSqw/Projet-jeu-tel---pc

## Organisation

- 01 · Grand écran : 25 vues, du salon aux quatre mini-jeux, révélations, classements et interruptions.
- 02 · Téléphones : 58 vues, inscription sans compte, avatar, commandes du chef, configurations, réponses, dessin, vote, chat et reconnexion.
- 03 · Administration et archives : 12 vues pour les contenus, tags, packs et import CSV / Excel. Les premières maquettes sont conservées dans une section d’archives.

Les écrans restent éditables : textes, cadres Auto Layout, composants et variables de couleur. Les huit réponses du blind test sont visibles simultanément sur la référence mobile 390 × 844.

Le prototype illustre des scénarios avec des données de démonstration. La synchronisation TV / téléphones, les scores calculés, la saisie réelle, les extraits audio et les dessins en direct relèvent de l’application future. Le QR code est illustratif ; le domaine de connexion reste à définir.

Les scripts de construction et les références de nœuds sont conservés dans ce dossier. Les règles métier validées sont dans `metier-plummo.md`, les parcours dans `parcours-et-ecrans-plummo.md`.

## Vérification finale

215 liens de navigation et 12 points de départ sont configurés. Le parcours salon → préparation → quiz a été testé dans le lecteur Figma. Les Plummos sont présents dans les composants et les écrans ; le salon illustre une bulle de chat. Les packs et leurs récapitulatifs ont été harmonisés.
