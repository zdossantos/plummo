# Le bluff des Plummos — plan d’implémentation

> Exécution native dans cette session, tâche par tâche.

**Objectif :** livrer le jeu de bluff validé dans l’issue #53.
**Architecture :** BluffGame orchestre les manches via GameEngine ; BluffAnswers regroupe les propositions et calcule les points. Les composants existants portent HUD, bonus, podium et administration.
**Stack :** Laravel 13 / PHP 8.4, Vue 3 / TypeScript, Bun 1.3.14.
**Spécification :** docs/superpowers/specs/2026-10-13-bluff-design.md

## Contraintes
Laravel valide les règles ; FR/EN ; aucun scroll ni pagination TV ; base plummo_testing seulement ; aucun secret ; PR puis squash après CI verte.

## Points de revue
Vérité et auteurs cachés avant révélation ; neuf cartes longues ; doublons dont sa propre réponse ; reconnexions et requêtes périmées ; dette temporelle appliquée au vote.
